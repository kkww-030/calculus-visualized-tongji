# 公式几何书 · Calculus Visualized（同济版）

> 同济版《高等数学》交互式可视化：每个公式背后，都藏着一个几何直觉。

21 个微积分核心定理的可交互动画演示，按同济大学《高等数学》（第七/八版）章节顺序组织。二维图形用 [Mafs](https://mafs.dev/) 绘制，三维场景用 [three.js](https://threejs.org/)（React Three Fiber）渲染，公式由 KaTeX 排版。纯前端静态站点，装好依赖后本地运行无需联网。

## 功能特点

- **21 个交互演示**：极限的 ε-δ 定义、导数、泰勒公式、黎曼和、微积分基本定理、微分方程、二次曲面、偏导数与切平面、重积分、格林/高斯公式、无穷级数、欧拉公式、傅里叶级数……
- **2D / 3D 自由切换**：欧拉公式、傅里叶级数等页面可在二维曲线与三维螺旋/曲面视图间切换，从不同视角理解同一对象。
- **可拖动 + 可播放**：拖动滑块或动点改变参数，也可让动画自动运行；三维场景支持鼠标旋转、滚轮缩放。
- **MATLAB 风格代码面板**：每个页面内置可编辑代码，修改参数（如函数、速度、区间）后点击「运行」，图形立即响应。
- **点击注释**：点击图形中的圆、动点、投影线、曲面等元素，弹出对应的几何含义说明。

## 目录（对应同济教材章节）

**上册 · 一元函数微积分**

1. 函数与极限：极限的 ε-δ 定义、两个重要极限
2. 导数与微分：导数的定义（割线逼近切线）
3. 微分中值定理与导数的应用：罗尔/拉格朗日中值定理、泰勒公式
4. 不定积分：原函数族与换元积分法
5. 定积分：黎曼和、牛顿–莱布尼茨公式
6. 定积分的应用：旋转体体积（2D/3D）、曲线弧长
7. 微分方程：斜率场与一阶方程的数值解

**下册 · 多元函数微积分**

8. 向量代数与空间解析几何：六种二次曲面（3D）
9. 多元函数微分法：偏导数与切平面（3D）、方向导数与梯度
10. 重积分：二重积分（3D）、三重积分（3D）
11. 曲线积分与曲面积分：格林公式、曲面积分与高斯公式（3D）
12. 无穷级数：审敛法、幂级数与收敛半径、欧拉公式（2D/3D）、傅里叶级数（2D/3D）

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org) 18 或更高版本
- npm（随 Node 一起安装）

### 启动步骤

```bash
# 1. 安装依赖（仅首次需要）
npm install

# 2. 启动本地开发服务器
npm run dev
```

启动后浏览器打开终端中显示的地址（默认为 <http://localhost:5173/>）即可使用。首页是按章节排列的卡片，点击任意卡片进入演示页。

### 其他命令

```bash
npm run build     # 构建生产版本，输出到 dist/
npm run preview   # 在本地预览构建产物
```

构建产物为纯静态文件，`dist/` 目录可部署到任意静态托管服务（如 GitHub Pages、Vercel、Netlify）。

## Windows 一键运行（可选）

仓库附带两个 PowerShell 脚本，方便不熟悉命令行的使用：

- `start-site.ps1`：检查 Node 环境 → 首次自动安装依赖 → 启动服务 → 打开浏览器
- `make-shortcut.ps1`：在桌面生成「公式几何书」快捷方式，之后双击即可运行

```powershell
# 在项目目录中右键「使用 PowerShell 运行」，或：
powershell -ExecutionPolicy Bypass -File .\start-site.ps1
powershell -ExecutionPolicy Bypass -File .\make-shortcut.ps1
```

## 项目结构

```
src/
├── App.jsx                 # 应用入口与 hash 路由
├── data/theorems.js        # 章节目录与每个定理的公式、直觉、操作说明
├── components/             # 通用组件（目录、页面框架、滑块、代码面板等）
├── matlab/                 # 轻量 MATLAB 语法解析器与参数双向绑定
└── visualizations/         # 各定理的交互演示
    ├── anim.js             # 动画时钟（rAF + 异常帧保护）
    ├── hit.js              # 图形点击命中检测
    └── three/              # 三维场景（R3F）与 Viz3D 容器
```
